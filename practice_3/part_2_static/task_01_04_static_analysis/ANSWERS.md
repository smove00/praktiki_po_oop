# Задания 1–4 по теме static

## Задание 1

Даны объект `f` класса `F`, обычные поле `i` и метод `imethod()`, статические поле `s` и метод `smethod()`.

1. `f.i` — можно.
2. `f.s` — можно, но лучше писать `F.s`.
3. `f.imethod()` — можно.
4. `f.smethod()` — можно, но лучше `F.smethod()`.
5. `F.i` — ошибка: поле не статическое.
6. `F.s` — можно.
7. `F.imethod()` — ошибка: нужен объект.
8. `F.smethod()` — можно.

## Задание 2

- `main()` — `static`, он запускается без создания объекта класса.
- `getCount()` — обычный метод, так как обращается к полю `count`.
- `factorial()` — можно сделать `static`, так как ему нужен только параметр `n`.

## Задание 3

Из статического метода нельзя напрямую вызвать обычный метод или взять обычное поле. Нужен объект.

В примере вызов `method1()` из `main()` исправлен на `new C().method1()`. Метод `method2()` тоже сделан обычным, так как он обращается к полю `circle`.
