# Практика 3, часть 2: задания 1–4

## Задание 1 — допустимые обращения к F

В методичке класс F содержит нестатические поле `i` и метод `imethod()`, статические поле `s` и метод `smethod()`; имеется объект `F f`.

| № | Выражение | Допустимо? | Объяснение |
|---|---|---|---|
| 1 | `System.out.println(f.i);` | Да | Доступ к полю экземпляра по объекту |
| 2 | `System.out.println(f.s);` | Да | Компилируется, но принято писать `F.s` |
| 3 | `f.imethod();` | Да | Вызов метода экземпляра |
| 4 | `f.smethod();` | Да | Компилируется, но принято писать `F.smethod()` |
| 5 | `System.out.println(F.i);` | Нет | Нестатическое поле нельзя использовать через имя класса |
| 6 | `System.out.println(F.s);` | Да | Статическое поле |
| 7 | `F.imethod();` | Нет | Нестатический метод требует экземпляр |
| 8 | `F.smethod();` | Да | Статический метод |

## Задание 2 — где нужен static

- `public static void main(String[] args)`: **static обязательно** как точка входа приложения.
- `getCount()` возвращает значение экземплярного поля `count`: **static не нужен**, иначе понадобится объект или нужно изменять смысл поля `count`.
- `factorial(int n)` зависит лишь от аргумента `n`: **static уместен**, если вызывается как самостоятельная служебная функция. Не является обязательным по синтаксису.

## Задание 3 — static и методы экземпляра

1. Без объекта экземплярный метод или поле непосредственно использовать из статического метода нельзя.
2. Из обычного метода можно вызывать статические методы и обращаться к статическим полям.
3. В примере метод `main` ошибочно обращался к `method1()` без объекта, а `static method2()` обращался к экземплярному полю `c`. Исправление: `new C().method1()`; сделать `method2()` экземплярным и хранить экземпляр `Circle` в объекте класса `C`. Альтернативно можно сделать и поле `c` статическим.
