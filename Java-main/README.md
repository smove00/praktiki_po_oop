
# Практические работы по Java

Репозиторий содержит выполненные практические работы по дисциплине «Объектно-ориентированное программирование» на языке Java.

## Практическая работа № 1. Основы Java

Изучение базового синтаксиса Java, переменных, массивов, циклов, условных конструкций и методов.

Выполненные задания:
- Вычисление суммы и среднего арифметического элементов массива.
- Поиск минимального и максимального элементов массива.
- Вывод аргументов командной строки.
- Вывод первых десяти членов гармонического ряда.
- Вычисление факториала числа с помощью метода.

## Практическая работа № 2. Классы и объекты

Изучение принципов создания классов и объектов, инкапсуляции данных, конструкторов, методов доступа и переопределения `toString()`.

Реализованы классы:
- `Author` — хранение и обработка информации об авторе.
- `Ball` — моделирование положения мяча и изменение его координат.
- `Student` — хранение информации о студенте и его оценке.

Для проверки работы классов созданы демонстрационные программы.

## Практическая работа № 3. Наследование, абстрактные классы и интерфейсы

Изучение наследования, абстрактных классов, переопределения методов, полиморфизма и реализации интерфейсов.

Реализованы:
- Иерархия геометрических фигур: `Shape`, `Circle`, `Rectangle` и `Square`.
- Абстрактный класс `Swim` и его производный класс `Swimmer`.
- Интерфейс `Movable` для перемещения объектов.
- Классы `MovablePoint`, `MovableCircle` и `MovableRectangle` для моделирования движения точек, окружностей и прямоугольников.

## Практическая работа № 4. Перечисления — «Времена года»

Изучение перечислений `enum`, конструкторов перечислений, методов экземпляров и оператора `switch`.

Реализовано перечисление `Season`, содержащее четыре времени года и их средние температуры.

Программа позволяет:
- Выводить информацию о любимом времени года.
- Получать среднюю температуру выбранного сезона.
- Определять описание времени года с помощью переопределения метода `getDescription()`.
- Использовать `switch` для вывода сообщения о любимом времени года.
- Перебирать все значения перечисления и выводить информацию о каждом сезоне.
