# Практические работы по объектно-ориентированному программированию (Java)

Репозиторий содержит решения по дисциплине «Объектно-ориентированное программирование» (РТУ МИРЭА).

## Структура

- **`practice_1/`** — первая учебная практика, четыре ранее выполненных проекта `PR1`–`PR4` (исходный код сохранён).
- **`practice_2/part_1_interfaces/`** — часть 1 из файла «ПР2 часть 1.pdf»: практическая работа № 6, интерфейсы Java.
- **`practice_2/part_2_implementation/`** — часть 2 из файла «ПР2 часть 2.pdf»: практическая работа № 7, реализация интерфейсов.
- **`practice_2/part_3_date_time/`** — часть 3 из файла «ПР2 часть 3.pdf»: практическая работа № 11, дата и время.

- **`practice_3/part_1_swing/`** — часть 1: практическая работа № 5, графический интерфейс Swing.
- **`practice_3/part_2_static/`** — часть 2: статические члены, объекты и секундомер.
- **`practice_3/part_3_swing/`** — часть 3: практическая работа № 15, компоненты и меню Swing.
- **`practice_4/part_1_recursion/`** — часть 1: практическая работа № 8, рекурсия Java (задачи 1–17).
- **`practice_4/part_2_exceptions/`** — часть 2: практическая работа № 18, обработка исключений Java (задания 1–8).

В практике 2 каждый самостоятельный пример находится в собственной папке, а задания, использующие общие классы, объединены в одну демонстрацию. В каталогах с диаграммами расположены редактируемые файлы `.drawio`.

## Практика 4

### Часть 1 — Практическая работа № 8: рекурсия

Решены **все 17 задач**: треугольная последовательность; вывод от 1 до n и от A до B; числа с заданной суммой цифр; сумма цифр; проверка простоты; разложение на простые множители; палиндром; последовательности без соседних нулей; разворот числа; количество единиц до двух нулей; вывод нечётных элементов; элементы с нечётными номерами; цифры слева направо и справа налево; число вхождений максимума; максимум последовательности.

Каждая задача находится в самостоятельном классе `Task01.java`–`Task17.java` и имеет метод `main`. Классы `Task11`, `Task12`, `Task13`, `Task16`, `Task17` используют вспомогательный `NumberReader.java` для чтения входных значений без глобальных переменных. `Task06` и `Task07` используют `PrimeDivisors.java` — рекурсивный поиск наименьшего делителя с ограниченной глубиной стека. Во всех решениях есть базовый случай и рекурсивный переход; для комбинаторных подсчётов применяется `BigInteger`.

**Примечание к методичке:** для задач 6 и 7 указана сложность `O(log n)`, но перебор пробных делителей до квадратного корня в общем случае имеет сложность `O(√n)`. Двоичное разбиение диапазона делителей снижает глубину рекурсии до `O(log n)`, но не снижает время полного перебора до `O(log n)` — это ограничение условий методички. Очень длинные входные последовательности в остальных рекурсивных задачах могут исчерпать стек вызовов.

### Часть 2 — Практическая работа № 18: исключения Java

Выполнены задания **1–8**. Демонстрируются целочисленное и вещественное деление на ноль, `ArithmeticException`, `NumberFormatException`, порядок блоков `catch`, `finally`, ручное создание `NullPointerException`, распространение исключений между методами, проверяемое `Exception`, оператор `throw`, объявление `throws`, повтор ввода некорректного ключа. Отдельный файл `Task01.java`–`Task08.java` на каждое задание. Для демонстраций из методички с заведомо некорректным кодом приведены компилируемые исправленные варианты и пояснения.
