# Практические работы по объектно-ориентированному программированию (Java)

Репозиторий содержит решения по дисциплине «Объектно-ориентированное программирование» (РТУ МИРЭА).

## Структура

- **`practice_1/`** — первая учебная практика, четыре ранее выполненных проекта `PR1`–`PR4` (исходный код сохранён).
- **`practice_2/part_1_interfaces/`** — часть 1 из файла «ПР2 часть 1.pdf»: практическая работа № 6, интерфейсы Java.
- **`practice_2/part_2_implementation/`** — часть 2 из файла «ПР2 часть 2.pdf»: практическая работа № 7, реализация интерфейсов.
- **`practice_2/part_3_date_time/`** — часть 3 из файла «ПР2 часть 3.pdf»: практическая работа № 11, дата и время.

- **`practice_3/part_1_swing/`** — часть 1: практическая работа № 5, графический интерфейс Swing.
- **`practice_3/part_2_static/`** — часть 2: статические члены, объекты и секундомер.
- **`practice_3/part_3_swing/`** — часть 3: практическая работа № 15, компоненты и меню Swing.

В практике 2 каждый самостоятельный пример находится в собственной папке, а задания, использующие общие классы, объединены в одну демонстрацию. В каталогах с диаграммами расположены редактируемые файлы `.drawio`.

## Практика 1

**PR1 — Основы Java:** массивы, сумма и среднее, минимум и максимум, аргументы командной строки, гармонический ряд, факториал.

**PR2 — Классы и объекты:** `Author`, `Ball`, `Student`; конструкторы, методы и инкапсуляция.

**PR3 — Наследование и полиморфизм:** `Shape`, `Circle`, `Rectangle`, `Square`, `Swim`, `Swimmer`, `Movable`, `MovablePoint`, `MovableCircle`, `MovableRectangle`.

**PR4 — Перечисления:** `Season`, температуры времён года, методы `enum`, `switch`.

Исходные пакеты `ru.mirea.pr1`–`ru.mirea.pr4` не изменены, их можно открывать как отдельные проекты.

## Практика 2

### Часть 1 — Практическая работа № 6: интерфейсы Java

- Задания **1, 2, 5**: интерфейс `Movable`, `MovablePoint`, `MovableCircle`, `MovableRectangle`; проверка одинаковой скорости точек, UML.
- **3**: `Nameable` для различных объектов.
- **4**: `Priceable` и получение цены.
- **6–9**: `Printable`, `Book`, `Shop`, `Journal`, обход массива интерфейсного типа.
- **10**: консольный магазин компьютеров (`Computer`, `Processor`, `Memory`, `Monitor`, `Brand`), добавление, удаление и поиск.
- **11**: конвертация Цельсий → Кельвин/Фаренгейт через `Convertable`.
- **12**: собственный `StringBuilder` с `undo()` (паттерн «Команда»).
- **13**: оповещение об изменении строки (паттерн «Наблюдатель»).
- **14**: демонстрации в коде; письменный отчёт в репозиторий не включён.

### Часть 2 — Практическая работа № 7: реализация интерфейсов

- **1–3**: `MovableRectangle`, `MovablePoint`, методы перемещения, `SpeedTest()`, UML.
- **4**: `MathCalculable`, `MathFunc`, степень, модуль комплексного числа и длина окружности.
- **5–6**: обработка строк (`ProcessStrings`): длина, нечётные позиции, обращение.
- **7–8**: `Printable`, `Book.printBooks()` и `Magazine.printMagazines()` с `instanceof`.
- **9**: проверка работы в демонстрационных программах.

### Часть 3 — Практическая работа № 11: дата и время

- **1**: фамилия разработчика, дата получения задания, текущее время сдачи (`Date`).
- **2**: сравнение введённой и текущей дат.
- **3**: `Student` с датой рождения и несколькими форматами даты.
- **4**: конструирование `Date` и `Calendar` из введённых пользователем данных.
- **5**: сравнение `ArrayList` и `LinkedList` при добавлении, вставке, удалении, поиске.

## Практика 3

### Часть 1 — практическая работа № 5: Swing

- **1**: табло матча AC Milan — Real Madrid с подсчётом голов, последней забившей командой и победителем.
- **2**: окно с 20 случайными цветными фигурами, унаследованными от абстрактного `Shape`.
- **3**: просмотр изображения по пути, переданному в аргументе командной строки.
- **4**: анимация из созданных программой кадров.

### Часть 2 — статические члены и объекты

- **1–4**: ответы на вопросы о `static`, исправленные примеры и работа с массивом дат.
- **5**: поиск круга с наибольшей площадью.
- **6**: `StopWatch`, UML-диаграмма и замер сортировки выбором 100 000 чисел.

### Часть 3 — практическая работа № 15: компоненты Swing

- **1**: калькулятор двух введённых чисел с четырьмя операциями.
- **2**: выбор страны через `JComboBox` и вывод сведений о ней.
- **3**: текстовый редактор с меню, двумя кнопками и сохранением в UTF-8.
- **4**: калькулятор с цифровыми кнопками и четырьмя операциями.

## Сборка и запуск

Нужен **JDK 8+** (предпочтительно JDK 17 или 21). Из корня репозитория:

```bash
mkdir -p build
javac -encoding UTF-8 -d build $(find practice_2 -name '*.java')
```

Запуск примера (имя пакета зависит от папки):

```bash
java -cp build ru.mirea.oop.p2.part1.movement.Main
java -cp build ru.mirea.oop.p2.part2.math.Main
java -cp build ru.mirea.oop.p2.part3.benchmark.Main
```

Остальные полные имена пакетов указаны в заголовках файлов `Main.java`. Для интерактивных заданий предусмотрен ввод через консоль. Диаграммы открываются в [diagrams.net](https://app.diagrams.net/). Результаты бенчмарка зависят от компьютера и не являются универсальными.

Для практики 3 из корня репозитория:

```bash
javac -encoding UTF-8 -d build $(find practice_3 -name '*.java')
java -cp build ru.mirea.oop.p3.part1.scoreboard.Main
java -cp build ru.mirea.oop.p3.part1.shapes.Main
java -cp build ru.mirea.oop.p3.part1.image.Main "/путь/к/изображению.png"
java -cp build ru.mirea.oop.p3.part1.animation.Main
java -cp build ru.mirea.oop.p3.part2.statics.Main
java -cp build ru.mirea.oop.p3.part2.circles.Main
java -cp build ru.mirea.oop.p3.part2.stopwatch.Main
java -cp build ru.mirea.oop.p3.part3.calculator.Main
java -cp build ru.mirea.oop.p3.part3.countries.Main
java -cp build ru.mirea.oop.p3.part3.editor.Main
java -cp build ru.mirea.oop.p3.part3.keypad.Main
```

Для графических примеров нужна графическая среда. Сортировка выбором 100 000 чисел может занять несколько секунд.
